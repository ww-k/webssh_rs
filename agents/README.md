# 通用开发代理

本目录保存与具体 AI 工具无关的开发角色说明。文件只描述职责、项目约定、工作流程和验证方式，不绑定模型名称、厂商命令或特定工具调用语法。

- `rust-api-implementer.md`：实现和修改 `src-server/` 的 Rust/Axum 后端功能。
- `ui-implementation-assistant.md`：实现和修改 `src-client/` 的 React/TypeScript 前端功能。
- `antd-llms-full.md`：Ant Design 组件语义和 API 参考资料，供前端实现代理查阅。

使用这些文件时，应同时遵守仓库根目录的 `AGENTS.md`，并以当前代码和配置为准。
